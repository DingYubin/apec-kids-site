# 部署上线说明

> 目标：让评委点开一个网址就能看到网页（评分维度"技术应用"明确要求：网页实现互联网线上部署、可在线访问）

---

## 一、方案 A：GitHub Pages（已配置，自动部署）

**线上地址**：https://dingyubin.github.io/apec-kids-site/

### 已经做好什么

- 工作流文件：`.github/workflows/deploy-pages.yml`
- 触发条件：只要往 `main` 分支推 `web/` 目录的改动，就**自动重新部署**，约 1-2 分钟生效
- 部署内容：`web/` 目录（即网站本体），不会把 `docs/`（含过程文档）暴露到网上

### 第一次启用（如果线上地址打不开）

GitHub → 打开仓库 `apec-kids-site` → **Settings** → 左侧 **Pages** → **Source** 选
**GitHub Actions**（只需做一次）。

然后回到仓库 **Actions** 标签页，看 `Deploy site to GitHub Pages` 是否跑成功（绿色 ✅）。

### 以后怎么更新

```bash
cd /Users/dingyubin/my-resp/apec-kids-site
git add -A && git commit -m "更新说明"
git push
```

推完等 1-2 分钟，刷新线上地址就是最新的。

### 小提醒

- 图片放进 `web/assets/` 再 push，线上会自动带上
- 首页加载时如果有图片还没生成，会显示 emoji 占位，**不会白屏**，不影响评委体验
- 手机打开同一个网址就能看手机端效果（卡片自动变 2 列）

## 二、方案 B：腾讯 EdgeOne Pages（国内访问更快，推荐作为最终提交地址）

GitHub Pages 在国内访问有时偏慢。如果要更稳，可以用腾讯云的 EdgeOne Pages 再挂一个域名：

1. 打开 https://edgeone.cloud.tencent.com/pages （用微信/QQ 登录）
2. 新建项目 → **导入 Git 仓库** → 授权 GitHub → 选择 `DingYubin/apec-kids-site`
3. 构建设置：
   - **框架预设**：无 / 静态网站（Static）
   - **构建命令**：留空（不需要构建）
   - **输出目录**：`web`
   - **根目录**：留空
4. 点击部署，等 1-2 分钟，会得到一个 `xxx.edgeone.app` 的免费域名
5. 把它记到提交材料里（可以同时给 GitHub Pages 和 EdgeOne 两个地址，写"备用地址"）

> EdgeOne Pages 的默认免费域名一般不需要自行备案；如果之后要绑自己的域名，才需要备案。
