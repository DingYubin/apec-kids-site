```bash

ssh apec 'sudo rsync -a --delete /tmp/apec-web/ /var/www/apec/ && sudo chown -R www-data:www-data /var/www/apec'
```

- 仓库内源文件：`tools/nginx-apec.conf`（含 gzip 压缩、静态资源缓存 7 天、独立日志）

```bash

```

## 二、备用地址：GitHub Pages

**地址**：https://dingyubin.github.io/apec-kids-site/

### 怎么更新

```bash
cd /Users/dingyubin/my-resp/apec-kids-site
git add -A && git commit -m "更新说明"     # 先提交
bash tools/deploy.sh                       # 推 gh-pages 分支
```

等 1-2 分钟刷新线上地址即可。发布的是 `web/` 目录内容（`docs/` 里的过程文档不会暴露到网上）。

> **机制说明**：GitHub Pages 的发布源是 **gh-pages 分支**（Settings → Pages → Deploy from a branch）。
> 往 gh-pages 推代码后，GitHub 会自动运行 "pages build and deployment" 构建（约 1 分钟）并发布。
> `tools/deploy.sh` 就是把 `web/` 最新内容拆出来强推到 gh-pages，一条命令完成发布。
> （早期尝试过的 Actions 自动部署工作流因账号权限限制一直失败，已删除。）
>
> 分支里已带 `.nojekyll`：关闭 Jekyll 处理，保证所有静态文件原样发布。

1. 打开 https://edgeone.cloud.tencent.com/pages （微信/QQ 登录）
2. 新建项目 → **导入 Git 仓库** → 选 `DingYubin/apec-kids-site`
3. 构建设置：静态网站；构建命令留空；**输出目录 `web`**
4. 部署后会得到一个 `xxx.edgeone.app` 免费域名，可作第三备用地址

> EdgeOne Pages 默认免费域名一般无需备案；绑定自有域名才需要备案。
