# 项目过程文档 ——《小鹏友的APEC朋友圈》

> 赛项：主题三 AI Coding 网页开发（小学组）｜作者：凯文（Kevin），深圳南山区的一名五年级学生｜2026年10月

---

## 一、页面功能介绍

这是面向 2026 年 APEC 深圳峰会的主题网页。我把 21 个成员经济体"变成"班里的 21 位同学，用一个深圳小学生的一天，回答"我和 APEC 有什么联系"。

1. **首页**：开场诗逐行浮现，21 个经济体的气泡围成一圈，卡通吉祥物"鹏小友"（取自深圳"鹏城"）打招呼。
2. **① 班级墙**：21 张经济体卡片，**点击翻面**看当地小朋友的问候语（日语、马来语、西班牙语……）；点星星收藏"想去的地方"，导航栏显示 ⭐ n/21，关掉网页也记得。
3. **② 朋友圈**：用朋友圈动态展示深圳凯文与日本、马来西亚、秘鲁小伙伴的一天，可以**点赞**。秘鲁的露娜说："我们相差 13 个小时，我说话的时候还在昨天。"
4. **③ 南山特色**：五张南山元素卡 + 一条 1980→2026 的深圳时间轴。
5. **④ 我的行动**：APEC 知识小测验（8 题，答对答错都有讲解，全对触发彩带）；留言墙可以写下想对亚太小朋友说的话，即时上墙；结尾诗《21盏小灯》每读一行点亮一盏，念完 21 盏全亮。

## 二、开发思路

先想清楚，再做出来。

**定角度**：APEC 是大人的会议，但深圳的小学生也是"小东道主"。所以不讲大道理，只讲我们的一天——我们和亚太小伙伴，在过很像的一天。

**定结构**：认识 21 个经济体 → 看看别人怎么生活 → 介绍我住的南山 → 我能做点什么 → 用诗收尾。

**定交互**：每个栏目都要能玩——卡片能翻、星星能点、题能答、留言能贴、诗能点亮。

**先文案后代码**：先写完文字再做页面；文字与数据集中在 `js/data.js`，改一句话不用碰 HTML。

**轻量**：天空、海面、城市剪影用 CSS 画，插画统一生成 WebP；图片缺失时自动显示 emoji/CSS 占位，不会报错；支持键盘操作和"减少动画"设置。

## 三、AI 辅助编码使用说明

| 环节 | 工具 | 人机分工 |
|------|------|----------|
| 资料查询 | 腾讯元宝 | AI 帮我查准 APEC 成员经济体、2026 峰会主题、深圳市花簕杜鹃、"三天一层楼"等；**事实由我逐条核对** |
| 文案 | 腾讯元宝 + 手写 | AI 出草稿，我改成五年级的语气，并加进自己真实的一天（早饭面条、操场跑步） |
| 编码 | 腾讯 CodeBuddy | 我提需求，CodeBuddy 写 HTML/CSS/JS；我打开看效果、指出问题、再来一轮 |
| 插画 | Muse AI | 我用统一风格提示词生成 38 张插画，并逐张检查文字、旗帜、地图、国界和人物一致性 |

**我怎么提要求**："做一个翻卡效果：点一下卡片转 180 度，正面是名字，背面是问候语，键盘也能操作。""点星星时数字从 0 变到 21，关掉再打开还要记得。""让这几行诗滚进画面时一行一行亮起来。"

**我的判断**：AI 第一版标题像课本，我改成了《小鹏友的APEC朋友圈》；AI 的句子偏成人，我改成小学生的口气；AI 画的旗帜类图案我全部换掉——小朋友的作品，不用旗帜和地图。

## 四、南山特色元素设计思路

我住南山，南山不用去查资料，它就在我上学路上。五张卡挑了五种气质：**深圳湾·人才公园**是"开放的海湾"（海对面就是香港）；**南头古城**是"历史的老家"（记录着深圳很早很早的故事）；**南山科技园**是"科技的客厅"（腾讯、大疆都在深圳成长，科技的终点是让生活更方便、让朋友更近）；**蛇口·海上世界与K11 ECOAST**是"敢闯的起点"（"时间就是金钱，效率就是生命"）；**前海**是"未来的窗口"（也许有一天，亚太的同学会来这里交朋友）。时间轴 1980 特区成立 → 20世纪80年代"三天一层楼" → 1998/2006 腾讯·大疆成长 → 2026 APEC 来深圳。

## 五、原创与合规说明

全站文案、结构、交互由本人创作，AI 只用于资料查询、代码辅助与插画生成。小葵、阿米尔、露娜是**虚构笔友**，不是真人；页面不用真人照片，不出现旗帜、国界与地图，也不公开学校与班级。
