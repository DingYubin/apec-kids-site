## 2. 栏目①：APEC是什么？

### 页面文案

**标题**：APEC，亚太"朋友圈"

**正文** 🔒：
> APEC 的全名是"亚太经济合作组织"，1989年成立，是我们亚太地区的"大家庭"。
>
> 这个大家庭里有 **21个成员经济体**，从中国到秘鲁，从俄罗斯到新西兰。大家凑在一起聊什么？聊怎么互相合作、怎么做生意更方便、怎么一起用好新技术、怎么让天更蓝、海更清。
>
> 2026年，这个大家庭的"大聚会"要开到深圳来啦！APEC 这是第三次来到中国——2001年在上海，2014年在北京，2026年，第一次来到深圳！
>
> 作为小东道主，我想先认识认识大家。往下走，看看我们的"亚太班级墙"！

**关键词标签** 🔒：`开放` `创新` `合作` `互联互通` `数字经济` `绿色低碳`

## 3. 栏目②：我的一天 vs Ta的一天

### 页面文案

**标题**：同样是早上7点，亚太的小伙伴在干什么？

**引子** ✏️（示例，让孩子改）：
> 我叫【主角名】，住在深圳南山，是一名五年级的小学生。
> 有一天我忽然想：日本的小学生几点上学？马来西亚的早餐吃什么？秘鲁的小朋友放学后干什么？
> 于是我把"我的一天"和"Ta的一天"放在了一起——

### "我的一天"时间轴 ✏️（全部由孩子填写真实细节！）

> 以下是填空示例，**必须换成孩子的真实生活**，越具体越好玩（审评委喜欢真实细节）。

| 时间 | 我在做什么 |
|------|-----------|
| 7:00 | 起床。早饭吃【✏️：肠粉？豆浆？汤米粉？】 |
| 7:50 | 背上书包出门，路上能看到【✏️：深圳湾？大沙河？校门口的榕树？】 |
| 12:00 | 在学校吃午饭，午休时【✏️：看书？和同桌下棋？】 |
| 16:30 | 放学后【✏️：写作业？打篮球？学编程？】 |
| 21:00 | 睡觉前【✏️：读一会儿书？和妹妹抢遥控器？】 |

### "Ta的一天"三个示例（草稿，✏️ 让孩子核实后改写）

**日本小学生**：
> 自己走路上下学，进学校要换上白色的室内鞋；午饭是全班一起吃的"给食"，值日生负责分餐；放学后，有的同学去学游泳，有的去练剑道。

**马来西亚小学生**：
> 班级里可能有不同民族的同学，大家用马来语、英语、华语聊天；早餐常常是一包椰浆饭；放学后参加课外活动，周末全家去夜市。

**秘鲁小学生**：
> 早上可能喝一杯热牛奶配面包，用西班牙语上课；下午放学帮爸爸妈妈做点小家务；周末去广场上玩，或者去看羊驼。

**结尾句** 🔒：
> 我们说着不同的话、吃着不同的饭、住在不同的地方，
> 但我们都一样：要上学、爱玩、想交到新朋友。

### 互动 ⚙️

> 时间轴滑块：拖动/点击切换"我 / 日本 / 马来西亚 / 秘鲁"，时间轴上的角色小人、早餐图标、场景背景跟着切换。每个"Ta的一天"配1张AI生成的小插画。

## 4. 栏目③：深圳·南山与APEC

### 页面文案

**标题**：从海边小村到APEC之城——我的家门口，就是故事发生的地方

**引子** 🔒：
> 你知道吗？我的城市深圳，40多年前还是一个小渔村。
> 而现在，2026年APEC峰会将在这里举办。
> 这中间发生了什么？我找到了几个"时间点"。

### 时间轴文案 🔒

| 年份 | 发生了什么 |
|------|-----------|
| 1980 | 深圳经济特区成立！小渔村开始"长大"。 |
| 1984 | 国贸大厦"三天一层楼"，全世界都看到了"深圳速度"。 |
| 1998 | 腾讯在深圳出生；2006年，大疆也在深圳出发。深圳造的产品，慢慢飞到了全世界。 |
| 2019 | 深圳成为"中国特色社会主义先行示范区"。 |
| 2026 | APEC峰会在深圳举办！21个经济体的大人们，来到我的城市。 |

### 南山元素卡 ✏️（孩子挑2-3个最有感觉的，换成自己的话）

| 地标 | 草稿文案 |
|------|---------|
| 深圳湾 & 人才公园 | 周末我在这里骑车。这个海湾是深圳"开放"的窗口——海的另一边就是香港。 |
| 南头古城 | 快1700岁的"老南山"，是深圳和香港共同的"老家"。石板路上藏着好多故事。 |
| 大沙河生态长廊 | 它以前是一条"臭水沟"，现在变成了穿过城市的"绿丝带"。 |
| 腾讯滨海大厦 & 大疆天空之城 | 把"深圳造"的科技送到亚太各地——说不定你用的软件和无人机就来自这里！ |
| 西丽湖 | 山环水绕的"科教城"，未来的科学家可能就在这里上学。 |

**结尾句** 🔒：
> APEC离我们远吗？不远。
> 它在深圳湾的风里，在南头古城的石板路上，也在我们的书包里。

### 互动 ⚙️

> 向下滚动，时间轴逐条点亮；南山元素卡悬停/点击弹出小插画。

> 深圳的小学生，也是小东道主！
> 我给自己定了三个"小行动"：

3. 留下一句话，送给我还没见过的亚太朋友们。

### 互动A：知识小测验 ⚙️（点击选项即时对错 + 得分）

**标题**：你是APEC小达人吗？答对全部6题有彩蛋！

| # | 题目 | 选项 | 答案 |
|---|------|------|------|
| 1 | 2026年APEC峰会在哪座城市举办？ | 北京 / 上海 / 深圳 / 广州 | 深圳 |
| 2 | APEC大家庭有多少个成员经济体？ | 10个 / 21个 / 50个 | 21个 |
| 3 | 深圳"三天一层楼"说的是哪座楼？ | 国贸大厦 / 腾讯大厦 / 双子塔 | 国贸大厦 |
| 4 | 在秘鲁，穿着"毛衣"很有名的动物是？ | 考拉 / 羊驼 / 大象 | 羊驼 |
| 5 | 日语里的"你好"怎么说？ | こんにちは / Xin chào / Salam | こんにちは |
| 6 | 下面哪个不是APEC的关键词？ | 开放 / 合作 / 独来独往 / 互联互通 | 独来独往 |

> ✏️ 让孩子自己再加 1-2 道题（例如关于南山、关于自己的）。
> ⚙️ 全对彩蛋：鹏鸟飞出来说"我在深圳等你来！"
