## 怎么跑

```bash
# 方式一：直接双击 web/index.html（最简单，图片也能显示）

# 方式二：起个本地服务（部署前自测更接近真实环境）
cd web && python3 -m http.server 8765
# 然后浏览器打开 http://localhost:8765
```

- **暂时没有插画也可以**：页面会自动降级成 emoji 占位，功能全部正常。
- **图片生成后**：按 `web/assets/README.md` 的文件名丢进去即可；如果是 png/jpg，
  改 `web/js/data.js` 第 9 行的 `ASSET_EXT` 一行即可全局切换。
