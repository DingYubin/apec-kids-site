## 怎么跑

```bash
# 方式一：直接双击 web/index.html（最简单，图片也能显示）

# 方式二：起个本地服务（部署前自测更接近真实环境）
cd web && python3 -m http.server 8765
# 然后浏览器打开 http://localhost:8765
```

- **38 张插画已生成**：包含首页背景、5 张头像、6 张朋友圈配图、21 张经济体卡和 5 张南山卡，均为 WebP。
- **图片兜底**：若资源缺失或加载失败，页面会自动回退成 emoji/CSS 占位，功能不受影响。
- **分享预览**：`web/assets/share/og-cover.jpg`（1200×630）已接入 Open Graph / Twitter Card 标签。
